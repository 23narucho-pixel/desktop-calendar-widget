바탕화면 캘린더 개인정보처리방침

시행일: 2026년 9월 18일

바탕화면 캘린더는 사용자의 Google Calendar 일정을 Windows 바탕화면에 표시하는 읽기 전용 앱입니다.

접근하는 정보

앱은 사용자가 승인한 Google 계정의 캘린더 목록, 캘린더 이름·색상과 일정의 제목·시간·장소를 읽습니다. Google 비밀번호에는 접근하지 않으며 일정을 생성·수정·삭제하지 않습니다.

정보 이용 목적

정보는 사용자가 선택한 캘린더와 일정을 월·주·일 위젯에 표시하고 자동 갱신하는 데만 사용합니다.

저장과 보안

OAuth 로그인 토큰과 일정 캐시는 사용자의 PC에 저장되며 Windows 데이터 보호 기능으로 현재 Windows 사용자 계정에 암호화됩니다. 앱 운영자는 캘린더 데이터를 별도 서버로 수집하거나 판매하지 않습니다.

공유

앱은 기능 제공에 필요한 Google Calendar API 통신 외에 Google 사용자 데이터를 제3자에게 전송하거나 공유하지 않습니다.

보관과 삭제

앱에서 계정 해제를 선택하면 저장된 로그인 토큰과 일정 캐시가 삭제됩니다. 앱 제거 기능으로도 로그인 정보와 일정 캐시를 삭제할 수 있습니다. 사용자는 Google 계정의 보안 설정에서 앱 접근 권한을 철회할 수 있습니다.

Google API 정책

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 따릅니다.
