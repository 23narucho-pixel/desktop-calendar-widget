바탕화면 캘린더

Google Calendar의 일정을 Windows 바탕화면에서 월·주·일 보기로 확인하는 읽기 전용 위젯입니다.

Windows용 다운로드개인정보처리방침

주요 기능

  • Google 계정으로 로그인하고 표시할 캘린더 선택
  • 월·주·일 보기와 오늘 날짜·공휴일 강조
  • 창 크기, 테마와 투명도 조절
  • PC 시작 시 자동 실행과 계정 연결 해제

다운로드

GitHub Releases에서 Windows 10/11 64비트용 휴대용 실행파일을 다운로드하세요.

Google 데이터 사용

캘린더 목록과 일정 내용을 읽어 위젯에 표시합니다. 일정을 생성·수정·삭제하지 않습니다. 로그인 토큰과 일정 캐시는 현재 Windows 사용자만 해독할 수 있도록 PC에 암호화하여 저장합니다.
